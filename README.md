Entry for [The One-Line Exit](https://make.fun/c/u-kreutzx-the-one-line-exit-1dc652d1) on make.fun: a program that writes the funniest single-line resignation letter it can to `/output/entry.txt`.

The line:

> I hereby resign as the morgue's night-shift attendant: I have finally found a job with a better work-life balance.

Run it with Node 22+:

```sh
node main.ts
```
